# 👁️ THE THIRD EYE — Premium E-Book Selling Platform

A visually stunning, modern, and cinematic digital bookstore built with React.js, Tailwind CSS, Framer Motion, and Three.js. Designed for curious minds seeking wisdom, inner growth, and life-changing literature.

---

## ✨ Features

- **Cinematic 3D Video Hero**: Immersive 3D perspective tilt on mouse movement with integrated custom video player, mute/unmute, and fullscreen cinema mode.
- **Curated Book Catalog**: Indian & global bestsellers (*Good Vibes, Good Life*, *Ikigai*, *Atomic Habits*, *The Mountain Is You*, *Think Like a Monk*).
- **Interactive Quick Reader Modal**: Authentic Cream Book Paper reader with customizable serif fonts, letter spacing, font-sizing, and dark/sepia/cream themes.
- **Dynamic Categories Grid**:
  - **Desktop**: Single continuous line with smooth horizontal mouse-wheel scroll & chevron controls.
  - **Mobile**: Responsive 4-items-per-row grid layout.
- **Ambient Sound Synthesizer**: Procedural Web Audio API soundscapes (432Hz Ambient Drone, Himalayan Monsoon Rain, Sacred Temple Bell).
- **Cart & Wishlist Drawers**: Real-time shopping cart with GST breakdown, promo discounts, and UPI checkout simulation.
- **Indian Payment Gateway Showcase**: QR Code Scan & Pay banner with official UPI, GPay, PhonePe, and Paytm integration visuals.
- **Testimonials Section**: Deep luxury night backdrop with warm cream book paper review cards.
- **High Visibility Real-Brand Social Icons**: Instagram, Facebook, X, YouTube, and LinkedIn in official brand colors.

---

## 🛠️ Tech Stack

- **Frontend**: React.js 18+ (Vite)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **3D & Graphics**: Three.js, Canvas Confetti
- **Icons**: Lucide React + Custom Inline SVGs
- **Typography**: Google Fonts (*Cinzel*, *Outfit*, *Plus Jakarta Sans*)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Aanchal7915/ebook_project.git
cd ebook_project
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5174](http://localhost:5174) in your browser.

### 4. Build for production
```bash
npm run build
```
